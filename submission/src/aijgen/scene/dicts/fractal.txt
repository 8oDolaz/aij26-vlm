# Fractal (RT-1) closed dictionary for SAM 3 (aijgen.scene, tools/sam3_probe.py): every object asked for on a Fractal
# frame.
# Fractal instructions name a fixed set of ~20 objects; all of them are here, plus the drawers they go into.
#
# One object per line. Names on one line, separated by " / ", are the same kind of object: where their boxes overlap
# strongly, only the best-scoring one is kept. Names ending in the same word ("coke can", "pepsi can") count as similar
# too. "name = prompt" asks SAM 3 with `prompt` and labels the box `name` (SAM 3 does not know the RXBAR brand).
